External sources

The app store for projects that never made it to a store.

Plenty of great Android apps only ever ship a release on their own forge. Omnify tracks those releases directly, so they install and update like any other app instead of being a file you re-download by hand every few months.

  • Picks the right APK for your CPU architecture automatically, with an optional name filter, and falls back to an older release when the latest has nothing compatible.
  • Shows the real app name and icon before you install, read from the release APK itself rather than guessed from the repo name.
  • Update notifications, signature-conflict handling, and the project README rendered inside the app.
  • Track a whole publisher account at once instead of adding one project at a time.
  • Per-source settings: custom name, pre-releases, version filters, mute. All included in your backup.

Everything else

Built to be used every day.

A daily-driver store, not a tech demo. Every feature below is in the app today.

Made for Android TV

A real 10-foot interface: full D-pad navigation, a scaled-up UI, automatic "Made for TV" detection for catalogue and external apps, and a curated pack of FOSS TV apps.

Modern Material You

Rebuilt in Jetpack Compose with Material 3: an accent-colour picker that can follow your wallpaper or an app's own icon, tinted system bars, edge-to-edge, and wavy progress indicators.

Discover home

A curated landing screen with carousels for what's new, recently updated and most downloaded, plus a browsable categories section.

Hide what you don't need

Hide any app, catalogue or external, from every list with one tap on its page. Manage what's hidden, or bring an app back, from Settings.

Built-in translation

Translate an app's summary and description into your language with online, self-hosted or fully offline on-device engines. Nothing is downloaded until you pick the on-device one.

Backup and restore

Back up repositories, external sources, settings, favourites and custom buttons independently, all in one file. Restoring only ever adds to what's there, it never wipes it.

Android TV

Not an afterthought.

Most stores on a TV box are a phone app you fight with a remote. Omnify has its own TV interface: a home screen with carousels, a navigation rail, detail pages built for the D-pad, and a curated pack of FOSS TV apps ready to install.

Security and privacy

Installing from anywhere should not mean trusting anything.

Every install path in Omnify verifies what it is about to hand to Android, and every check it runs is visible to you rather than hidden behind a spinner.

  • The signing certificate is verified against the repository index before any install, with the installed and expected fingerprints viewable and copyable on the detail screen.
  • Anti-feature warnings and the full runtime-permission list on every app page.
  • A badge flags apps that depend on proprietary Google services, and how well microG actually covers what they need.
  • The optional GitHub token is scope-less: it only lifts the API rate limit, it can do nothing else.
  • Translation can run fully offline on your device, with no service to trust.

This is a beta.

The core is solid and it gets used every day, but there is no point pretending it is already fully polished. External sources deserve the closest look right now: every project structures its releases a little differently, and a pattern only becomes reliable once it has been seen on a real repository.

If an app's icon, name, version, tags, languages or Google-services badge looks wrong, that report is genuinely useful. It is never just noise.
